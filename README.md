# max2tg (Fork)

Двусторонний мост между мессенджером **Max** и **Telegram** с поддержкой тем форума (Topics), цитирования, досылки истории и удаления сообщений.

> **Оригинальный проект:** Этот репозиторий является форком проекта [Aist/max2tg](https://github.com/Aist/max2tg) от Ильи Острерова ([@Aist](https://github.com/Aist)). Спасибо автору за создание базового клиента!

---

## Возможности и отличия этого форка

- 📂 **Форумные темы (Telegram Topics):** каждый чат и контакт из Max автоматически создаётся как отдельная тема в супергруппе Telegram (с установкой аватарки чата).
- 💬 **Прямой ввод без кнопок:** в теме форума можно просто писать сообщения — они автоматически уходят в соответствующий чат Max.
- ↩️ **Сквозные ответы (Replies):** нативный ответ на сообщение в Telegram цитирует оригинальное сообщение в Max (и наоборот).
- 🔄 **Двусторонняя синхронизация истории:** при запуске или переподключении бот автоматически проверяет и досылает пропущенные сообщения в строгом хронологическом порядке без дубликатов.
- 🗑️ **Удаление сообщений в Max:**
  - Командой `/del` (или `/delete`, `/rm`) в ответ на пересланное сообщение.
  - Реакцией 🗑️ или ❌ на пересланное сообщение.
- 👍 **Подтверждение доставки:** бот ставит реакцию (по умолчанию `👍`) на ваше сообщение в Telegram, подтверждая успешную отправку в Max.
- 🎨 **Чистое форматирование:** понятное оформление отправителей (`👤 <b>Имя</b>`), двойные переносы строк, корректная обработка цитат и пересылок.
- 📎 **Все типы медиа:** текст, фото, видео, документы, голосовые/аудио, стикеры, контакты, локации, опросы.
- 🛡️ **Безопасность:** бот не передаёт токен Telegram-бота сторонним серверам при загрузке файлов.

## Быстрый старт

### 1. Получение данных

#### Max (`MAX_TOKEN` и `MAX_DEVICE_ID`):
1. Откройте [web.max.ru](https://web.max.ru) в браузере и войдите в аккаунт.
2. Откройте DevTools (`F12`) → вкладка **Application** (или **Storage** в Firefox) → **Local Storage** → `https://web.max.ru`.
3. Скопируйте:
   - `__oneme_auth` → значение поля `"token"` (это `MAX_TOKEN`).
   - `__oneme_device_id` → значение целиком (это `MAX_DEVICE_ID`).
4. **Важно:** закройте вкладку `web.max.ru` после копирования, чтобы избежать конфликта сессий и блокировки аккаунта.

#### Telegram (`TG_BOT_TOKEN` и `TG_CHAT_ID`):
1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Создайте группу в Telegram, включите в её настройках **Темы (Topics)** и добавьте бота с правами администратора (для создания тем).
3. Узнайте ID группы (например, через [@userinfobot](https://t.me/userinfobot) — для групп ID начинается с минуса).

---

### 2. Запуск

#### Вариант 1: Быстрый запуск через Docker Compose (рекомендуется)

Вам даже не нужно клонировать весь репозиторий — образ уже собран и готов к работе в GitHub Container Registry (`ghcr.io/type-rro/max2tg:latest`).

1. Создайте рабочую папку и перейдите в неё:
   ```bash
   mkdir max2tg && cd max2tg
   ```

2. Скачайте `docker-compose.yml` одной командой:
   ```bash
   curl -O https://raw.githubusercontent.com/Type-RRO/max2tg/main/docker-compose.yml
   ```
   *(Либо создайте файл `docker-compose.yml` вручную и вставьте содержимое:)*
   ```yaml
   services:
     max2tg:
       image: ghcr.io/type-rro/max2tg:latest
       container_name: max2tg
       restart: unless-stopped
       env_file:
         - .env
       environment:
         - PYTHONUNBUFFERED=1
         - LOG_DIR=/app/logs
         - DATA_DIR=/app/data
       volumes:
         - ./logs:/app/logs
         - ./data:/app/data
   ```

3. Скачайте шаблон конфигурации и укажите свои токены:
   ```bash
   curl -o .env https://raw.githubusercontent.com/Type-RRO/max2tg/main/.env.example
   nano .env   # укажите MAX_TOKEN, MAX_DEVICE_ID, TG_BOT_TOKEN, TG_CHAT_ID
   ```

4. Запустите контейнер:
   ```bash
   docker compose up -d
   ```

Полезные команды:
```bash
# Просмотр логов в реальном времени
docker compose logs -f

# Перезапуск
docker compose restart

# Остановка
docker compose down
```

> **Персистентность данных:** Все данные бота (файлы тем, история, карта связки сообщений) автоматически сохраняются на вашем хосте в папку `./data`, а логи — в `./logs`.

---

#### Вариант 2: Локально из исходников (Python)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Type-RRO/max2tg.git
   cd max2tg
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Настройте конфигурацию:
   ```bash
   cp .env.example .env
   nano .env  # укажите ваши токены
   ```

4. Запустите:
   ```bash
   python -m app.main
   ```

## Основные параметры `.env`

| Переменная | Описание | По умолчанию |
|---|---|---|
| `MAX_TOKEN` | Токен авторизации Max | *обязательно* |
| `MAX_DEVICE_ID` | UUID устройства Max | *обязательно* |
| `TG_BOT_TOKEN` | Токен Telegram-бота | *обязательно* |
| `TG_CHAT_ID` | ID чата / супергруппы с темами | *обязательно* |
| `REPLY_ENABLED` | Разрешить ответы из Telegram в Max | `true` |
| `ENABLE_TOPICS` | Создавать темы для каждого чата Max | `true` |
| `SHOW_REPLY_BUTTON` | Показывать inline-кнопку «Ответить» под сообщениями | `false` |
| `DELIVERY_REACTION` | Эмодзи реакции при подтверждении доставки | `👍` |
| `SYNC_HISTORY_COUNT` | Количество сообщений для синхронизации при старте | `20` |
| `MAX_PROXY` | SOCKS5-прокси для подключения к Max | — |
| `TG_PROXY` | SOCKS5-прокси для подключения к Telegram | — |
| `MAX_CHAT_IDS` | Фильтр: слушать только указанные чаты через запятую | все |
| `MAX_EXCLUDE_CHAT_IDS` | Исключить чаты из пересылки | — |

## Правила безопасности (как не получить бан в Max)

Система защиты Max (VK) реагирует на аномалии сессии:
1. **Не держите открытой веб-версию:** если вкладка `web.max.ru` открыта одновременно с ботом, сервер сбрасывает сессию.
2. **Используйте совпадающий `MAX_DEVICE_ID`:** токен привязан к ID устройства.
3. **Единый IP/прокси:** если для бота используется `MAX_PROXY`, получайте токен в браузере через этот же прокси, чтобы не было прыжков между разными провайдерами/странами.
