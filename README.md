# max2tg (Fork)

Двусторонний мост между мессенджером **Max** и **Telegram** с поддержкой тем форума (Topics), сквозных ответов, автоматической досылки истории без дубликатов и удаления сообщений.

> **Оригинальный проект:** Этот репозиторий является форком проекта [Aist/max2tg](https://github.com/Aist/max2tg) от Ильи Острерова ([@Aist](https://github.com/Aist)). Спасибо автору за создание базового клиента!

---

## Возможности и отличия этого форка

- 📂 **Форумные темы (Telegram Topics):** каждый чат и контакт из Max автоматически создаётся как отдельная тема в супергруппе Telegram.
- 💬 **Прямой ввод без кнопок:** в теме форума можно просто писать сообщения — они автоматически уходят в соответствующий чат Max.
- ↩️ **Сквозные ответы (Replies):** нативный ответ на сообщение в Telegram цитирует оригинальное сообщение в Max (и наоборот).
- 🔄 **Умная синхронизация истории (без дубликатов):** при запуске или переподключении бот сверяет базу отправленных сообщений, сортирует пропущенные строго хронологически (от старых к новым) и последовательно досылает их.
- 🗑️ **Удаление сообщений в Max:**
  - Командой `/del` (или `/delete`, `/rm`) в ответ на пересланное сообщение.
  - Реакцией 🗑️ или ❌ на пересланное сообщение в Telegram.
- 👍 **Подтверждение доставки:** бот ставит реакцию (по умолчанию `👍`) на ваше сообщение в Telegram, подтверждая успешную отправку в Max.
- 🎨 **Чистое форматирование:** аккуратное оформление отправителей (`👤 <b>Имя</b>`), двойные переносы строк, корректная обработка цитат и пересылок.
- 📎 **Все типы медиа:** текст, фото, видео, документы, голосовые/аудио, стикеры, контакты, локации, опросы.
- 🛑 **Graceful Shutdown:** чистое завершение работы по `Ctrl+C` / `SIGTERM` без зависаний и логов с ошибками.

## 🔑 Получение токенов и авторизация

### 1. Telegram (`TG_BOT_TOKEN` и `TG_CHAT_ID`)
1. Создайте бота через [@BotFather](https://t.me/BotFather) и сохраните токен (`TG_BOT_TOKEN`).
2. Создайте супергруппу в Telegram, откройте её настройки и включите тумблер **Темы (Topics / Форум)**.
3. Добавьте вашего бота в группу и назначьте его **Администратором** с правом управления темами (Manage Topics).
4. Узнайте ID группы (например, через [@userinfobot](https://t.me/userinfobot) — для групп ID начинается с минуса, например `-1001234567890`).

---

### 2. Max (`MAX_TOKEN` и `MAX_DEVICE_ID`)

> [!IMPORTANT]
> **Как работает антифрод Max:**
> Токен авторизации Max привязывается к IP-адресу и ID устройства (`MAX_DEVICE_ID`). 
> Если вы авторизуетесь в браузере с домашнего IP в РФ, а затем запустите бота на зарубежном VPS (например, в Финляндии или Германии), сервер Max может обнаружить резкую смену подсети и аннулировать токен (`login.token: Ошибка входа`).
> 
> **Решение:** если вы разворачиваете бота на удалённом сервере, получите токен через **SSH-туннель** этого сервера.

#### Способ А: Получение токена для удаленного сервера (через SSH SOCKS-туннель)

Этот метод гарантирует 100% совпадение IP между браузером при входе и ботом на сервере:

1. **Поднимите SOCKS-туннель на вашем локальном компьютере:**
   ```bash
   ssh -D 1080 -f -N user@IP_ВАШЕГО_СЕРВЕРА
   ```
   *(Флаг `-D 1080` создаёт локальный SOCKS5-прокси, `-f -N` переводит туннель в фоновый режим)*.

2. **Запустите браузер через туннель в изолированном профиле:**
   > Флаг `--user-data-dir` обязателен: без него браузер просто откроет вкладку в уже запущенном процессе и проигнорирует параметры прокси.

   - **Linux (Chromium / Chrome):**
     ```bash
     chromium --user-data-dir=/tmp/chromium-proxy --incognito --proxy-server="socks5://127.0.0.1:1080" https://web.max.ru
     ```
   - **macOS (Google Chrome):**
     ```bash
     /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --user-data-dir=/tmp/chrome-proxy --incognito --proxy-server="socks5://127.0.0.1:1080" https://web.max.ru
     ```
   - **Windows (PowerShell):**
     ```powershell
     Start-Process chrome.exe -ArgumentList '--user-data-dir="$env:TEMP\chrome-proxy"', '--incognito', '--proxy-server="socks5://127.0.0.1:1080"', 'https://web.max.ru'
     ```
   *(Также можно использовать расширения **SwitchyOmega** или **FoxyProxy**, настроив SOCKS5 на `127.0.0.1:1080`)*.

3. **Скопируйте токен:**
   - Войдите в свой аккаунт Max по номеру телефона / SMS.
   - Нажмите `F12` (DevTools) → перейдите во вкладку **Application** (в Firefox — **Storage**) → слева разверните **Local Storage** → выберите `https://web.max.ru`.
   - Скопируйте:
     - `__oneme_auth` → значение внутри JSON поля `"token"` (это `MAX_TOKEN`).
     - `__oneme_device_id` → значение целиком (это `MAX_DEVICE_ID`).
4. **Закройте окно браузера:**
   Обязательно закройте вкладку/окно `web.max.ru` после копирования данных, чтобы веб-версия не отправляла параллельные heartbeat-запросы на тот же `device_id`.

#### Способ Б: Получение токена для локального запуска
Если вы запускаете бота на том же компьютере, просто откройте [web.max.ru](https://web.max.ru) в обычном браузере, скопируйте `MAX_TOKEN` и `MAX_DEVICE_ID` по инструкции выше и закройте вкладку.

## 🚀 Развертывание

### Вариант 1: Docker Compose (рекомендуется)

Готовый образ автоматически собирается и публикуется в GitHub Container Registry: `ghcr.io/type-rro/max2tg:latest`.

1. Создайте рабочую директорию:
   ```bash
   mkdir max2tg && cd max2tg
   ```

2. Скачайте `docker-compose.yml`:
   ```bash
   curl -O https://raw.githubusercontent.com/Type-RRO/max2tg/main/docker-compose.yml
   ```
   *(Либо создайте файл `docker-compose.yml` со следующим содержимым:)*
   ```yaml
   services:
     max2tg:
       image: ghcr.io/type-rro/max2tg:latest
       container_name: max2tg
       restart: unless-stopped
       env_file:
         - .env
       environment:
         - PYTHONUNBUFFERED=1
         - LOG_DIR=/app/logs
         - DATA_DIR=/app/data
       volumes:
         - ./logs:/app/logs
         - ./data:/app/data
   ```

3. Скачайте шаблон `.env` и заполните ваши токены:
   ```bash
   curl -o .env https://raw.githubusercontent.com/Type-RRO/max2tg/main/.env.example
   nano .env
   ```

4. Запустите контейнер:
   ```bash
   docker compose up -d
   ```

#### Управление контейнером:
```bash
# Просмотр логов в реальном времени
docker compose logs -f

# Перезапуск
docker compose restart

# Остановка
docker compose down

# Обновление до свежей версии
docker compose pull
docker compose up -d
```

> [!TIP]
> **Персистентность данных (том `./data`):**
> Папка `./data` монтируется на диск хоста и содержит:
> - `topics.json` — сохранённая связь чатов Max с ID тем Telegram.
> - `seen_messages.json` — база обработанных сообщений для защиты от дубликатов.
> - `messages_map.json` — маппинг сообщений для ответов и удаления.
> 
> Благодаря сохранению этой папки, при перезапусках контейнера или обновлении токена **не создаются дубликаты тем и не пересылаются повторные сообщения**.

### Вариант 2: Запуск из исходников (Python)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Type-RRO/max2tg.git
   cd max2tg
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создайте `.env` и укажите параметры:
   ```bash
   cp .env.example .env
   nano .env
   ```

4. Запустите мост:
   ```bash
   python -m app.main
   # или напрямую:
   python app/main.py
   ```

## ⚙️ Параметры конфигурации (`.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `MAX_TOKEN` | Токен авторизации сессии Max | *обязательно* |
| `MAX_DEVICE_ID` | UUID устройства Max | *обязательно* |
| `TG_BOT_TOKEN` | Токен бота Telegram | *обязательно* |
| `TG_CHAT_ID` | ID супергруппы Telegram с включёнными темами | *обязательно* |
| `REPLY_ENABLED` | Разрешить ответы из Telegram обратно в Max | `true` |
| `ENABLE_TOPICS` | Создавать темы форума для каждого чата Max | `true` |
| `SHOW_REPLY_BUTTON` | Показывать кнопку «Ответить» под сообщениями | `false` |
| `DELIVERY_REACTION` | Эмодзи реакции-подтверждения доставки в Max | `👍` |
| `HISTORY_MESSAGES_COUNT` | Глубина проверки истории при старте/реконнекте | `100` |
| `HISTORY_POLL_INTERVAL` | Интервал фоновой сверки истории (в секундах) | `60` |
| `MAX_PROXY` | SOCKS5-прокси для подключения к Max | — |
| `TG_PROXY` | SOCKS5-прокси для подключения к Telegram | — |
| `MAX_CHAT_IDS` | Фильтр: пересылать только указанные чаты (через запятую) | все |
| `MAX_EXCLUDE_CHAT_IDS` | Исключить чаты из пересылки (через запятую) | — |
| `DEBUG` | Подробный вывод отладки в консоль и папку `debug/` | `false` |

## 🛡️ Безопасность и стабильность сессии

1. **Не держите открытой веб-версию `web.max.ru`:** если вкладка браузера активна одновременно с ботом, сервер Max аннулирует сессию из-за конфликта `device_id`.
2. **Всегда обновляйте параметры в паре:** `MAX_TOKEN` всегда должен соответствовать тому `MAX_DEVICE_ID`, с которым он был получен.
3. **Стабильный IP:** не используйте публичные/бесплатные прокси. При запуске на сервере используйте SSH-туннель для первоначального получения токена.
